Setup en 3 pasos: 1. Crear el vault: git clone https://github.com/hgvc-publish/wf-template.git ~/ObsidianVault cd ~/ObsidianVault chmod +x usar-skill.sh usar-agente.sh 2. Cablear las reglas globales en ~/.claude/CLAUDE.md: @import(/home/$USER/ObsidianVault/00-Reglas-Globales/CLAUDE-global.md) 3. Activar las skills y agentes seleccionados: ./usar-skill.sh --global ./usar-agente.sh --global ... Verificación: abrí Claude Code y probá /fase, /lucide, /vengadores. Backup: el vault es un repo git → hacé push a un remoto privado para nunca perder la estructura.
